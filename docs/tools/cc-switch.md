# 安装 cc-switch

## 这是干嘛的

cc-switch 是一个**切换工具**：帮你在一个界面上切换 Claude Code 用哪个「大脑」（模型供应商）。

打个比方：Claude Code 是一辆车，cc-switch 是**换挡杆**——你不用打开发动机舱手动改配置，点一下就能从「官方模型」切到「国内模型」，省事又不容易出错。

> 💡 **普通同事可以跳过这页**：如果你只用一个固定的模型，不需要装它。它主要给需要切换不同模型的人用。

---

## 装之前准备

- 已经装好 **Claude Code**（见 [Claude Code 页](/tools/claude-code)）
- 装好 **Node.js**（同上）

---

## 安装步骤（图形界面版）

我们用**带图形界面的桌面版**，最省事：

1. 打开浏览器，访问 cc-switch 的 GitHub 发布页（下载地址问 IT 要，或见下方）
2. 找到 **Windows 安装包**（文件名以 `.msi` 结尾）
3. 下载后双击运行，一路「下一步」安装

> 📸 【截图占位】cc-switch 下载页面，红框标出 .msi 安装包

4. 安装完成后，桌面或开始菜单会出现 cc-switch 图标，双击打开

> 📸 【截图占位】cc-switch 打开后的主界面

---

## 怎么用它切换模型

打开 cc-switch 后，界面会列出不同的供应商配置（比如 Anthropic、DeepSeek 等）：

1. 选中你要用的那个
2. 点击「切换」或「应用」
3. 之后打开 Claude Code，就会用你选的那个模型了

> 📸 【截图占位】切换供应商配置的操作步骤

---

## 常见问题

### 1. 打开后列表是空的

说明还没配置过供应商。第一次需要先「新建」一个配置，填入 API Key 和接口地址——**这一步找 IT 帮你配**，不要自己乱填。

### 2. 切换后 Claude Code 报错

多半是那个供应商的 API Key 没填对，或者接口地址填错了。回到 cc-switch 检查配置，或找 IT。
