# 安装 Hermes Agent

## 这是干嘛的

Hermes Agent 是一个**带图形界面的桌面 AI 助手**（Nous Research 出品）。

和 Claude Code 最大的区别：**它有窗口、能点按钮，不用碰命令行**。打开桌面图标就能用，就像打开一个普通的软件。如果你对命令行发怵，这个最适合你。

---

## 装之前准备

几乎没有——它会**自动帮你装好所有依赖**（Python、Node.js 这些），你只需要能联网。

---

## 安装步骤（推荐：图形界面安装）

### 第 1 步：下载安装程序

1. 打开浏览器，访问官网：<https://hermes-agent.nousresearch.com/>
2. 下载 **Windows 安装程序**（.exe 文件）

<!-- 截图待补：Hermes Agent 官网首页，红框标出下载按钮 -->

### 第 2 步：处理 Windows 安全提示

双击安装程序时，Windows 可能会弹出蓝色的 SmartScreen 警告（说"已保护你的电脑"）。**这是正常的**，因为安装程序没做代码签名。

1. 点「**更多信息**」
2. 再点「**仍要运行**」

<!-- 截图待补：SmartScreen 警告弹窗，红框标出"更多信息"和"仍要运行" -->

### 第 3 步：一路「下一步」

安装程序会自动下载依赖、配置环境，可能要等几分钟。中间弹出什么就点「确定」/「下一步」。

<!-- 截图待补：安装过程画面 -->

---

## 首次启动

安装完成后，桌面出现 Hermes 图标，双击打开。第一次启动会进入向导：

- **本地模式**：在你电脑上跑（推荐）
- **远程模式**：连远程服务器（需要 IT 提供地址和 Key）

按向导提示选「本地模式」，配置好模型就能用了。

<!-- 截图待补：首次启动的向导界面 -->

## 验证装好了

打开 Hermes Agent 后，如果能正常进入对话界面，输入一句话（比如"你好"），它正常回复，就说明装好了。

---

## 常见问题

### 1. SmartScreen 警告要不要担心？

不用。这是开源软件的常见情况，点「仍要运行」即可。安装程序来自官网，是安全的。

### 2. 安装卡住不动

可能在下载依赖（Python 等），耐心等几分钟。如果长时间不动，关掉重新打开安装程序。

### 3. 和 Claude Code 用哪个？

- **想点按钮、不想碰命令行** → 用 Hermes Agent
- **想深度干活（读文件、写代码、自动化）** → 用 Claude Code

两个可以都装，按需选择。

---
