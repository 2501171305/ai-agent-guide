# 安装 Claude Code

## 这是干嘛的

Claude Code 是 Anthropic 官方的 AI 助手，这里我们用它的 **VS Code 插件版**——在 VS Code（一个写代码/看文件的编辑器）里用，有完整的图形界面，不用碰命令行。

装好后，你在 VS Code 右侧/左侧能看到一个聊天面板，用大白话告诉它要做什么，它就能读文件、写代码、帮你干活。

---

## 装之前准备两样

1. **VS Code** —— 一个免费的编辑器，先装它
2. **账号/密钥** —— 找 IT 领取（公司用的是国内模型，登录方式问 IT）

---

## 第 1 步：安装 VS Code

1. 打开浏览器，访问 <https://code.visualstudio.com>
2. 下载 Windows 版本，双击安装
3. 一路「下一步」，默认选项就行

> 📸 【截图占位】VS Code 官网下载页，红框标出下载按钮

---

## 第 2 步：安装 Claude Code 插件

1. 打开 VS Code
2. 按键盘 `Ctrl + Shift + X`（三个键同时按），打开**扩展市场**（左侧的方块图标）
3. 在搜索框输入 `Claude Code`
4. 认准发布者是 **Anthropic** 的「Claude Code for VS Code」，点「安装」

> 📸 【截图占位】VS Code 扩展市场搜索 Claude Code，红框标出 Anthropic 官方那个

> ⚠️ **注意**：搜索会出现好几个名字类似的，一定要认准「Anthropic」官方发布的，别装成第三方仿冒的。

---

## 第 3 步：验证装好了

装完后，VS Code 左侧活动栏会出现一个 **Claude Code 图标**（火花/Spark 形状）。点一下，右侧弹出聊天面板，就说明装好了。

如果没看到图标，**关掉 VS Code 重新打开**。

> 📸 【截图占位】VS Code 左侧出现 Claude Code 图标 + 聊天面板

---

## 第 4 步：登录

第一次点开面板，会提示登录。公司用的是国内模型，**登录方式（账号还是密钥）问 IT**，照着配就行。

> 📸 【截图占位】首次登录界面

---

## 常见问题

### 1. 搜索不到 Claude Code 插件

确认 VS Code 是最新版（1.98 以上），或者关了重开再搜。

### 2. 装了但图标不显示

- 先**打开一个文件**（只打开文件夹可能不显示）
- 再不行就**重启 VS Code**

### 3. 登录后一直连不上

多半是网络或账号问题，找 IT 处理。
