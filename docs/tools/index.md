# 工具安装

先说明：工具没有“哪个最好”，只有“哪个适合你的用法”。零基础同事不要从本页逐项安装，先走 [30 分钟上手](/quickstart/)；已经装过工具的同事再从下面选择。

## 按需求选择

| 我想做什么 | 推荐工具 | 说明 |
| --- | --- | --- |
| 第一次上手，不知道装什么 | [Claude Code](/tools/claude-code) | 按 30 分钟路径走，搭配 cc-switch 接入公司模型 |
| 已在用 ChatGPT，想让它读文件、干活 | [Codex](/tools/codex) | 在 ChatGPT 桌面应用中切换到 Codex 模式 |
| 不想碰命令行，希望有独立桌面界面 | [Hermes Agent](/tools/hermes-agent) | 图形界面安装，适合先熟悉 Agent 的基本用法 |
| 需要在多个模型供应商之间切换 | [cc-switch](/tools/cc-switch) | 30 分钟路径用它完成首次模型接入 |
| 想让 Agent 先认识你的岗位和工作习惯 | [画像采集](/tools/profile-interview) | Hermes Agent 的初始设置提示词，可复用到其他 Agent |

## 推荐上手顺序

1. 先走 [30 分钟上手](/quickstart/)，完成豆包、cc-switch、VS Code 和 Claude Code 的安装。
2. 按 [模型接入](/setup/) 配置公司使用的 DeepSeek 和豆包。
3. 阅读 [内部经验手册](/experience/how-to-ask)，再开始处理真实工作。
4. 想进一步定制时，再使用 [画像采集](/tools/profile-interview)。

## 安全底线

API Key 等同于账号密码。不要发到群里、贴进文档、截图外传，也不要复制给同事代填。发现 Key 可能泄露时，立即联系 IT 重新生成。
