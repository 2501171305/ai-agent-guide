# ③ 装 VS Code + Claude Code，开始干活

VS Code 是看文件/写代码的编辑器，Claude Code 是装在里面帮你干活的 AI。装完这套，就能开始对话了。

## 操作步骤

### 1. 让豆包帮你装 VS Code

把这句话**原样复制**发给豆包：

::: tip 📋 发给豆包的话
帮我安装 VS Code 最新版，在我的 D 盘，并在桌面上放快捷方式
:::

### 2. 在 VS Code 里装 Claude Code 插件

1. 打开 VS Code
2. 按 `Ctrl + Shift + X`（三个键同时按），打开扩展市场
3. 搜索 `Claude Code`
4. 认准发布者是 **Anthropic** 的那个，点「安装」

::: warning ⚠️ 别装错
搜索会出现好几个名字类似的，**认准发布者「Anthropic」**，别装第三方仿冒的。
:::

### 3. 装中文包（可选但推荐）

在扩展市场再搜 `Chinese`，装「Chinese (Simplified) 中文（简体）语言包」，然后重启 VS Code 就是中文界面了。

### 4. 启动密钥，开始对话

1. 回到 **cc-switch**，点「启动/切换」你接好的密钥
2. **完全关掉 VS Code，重新打开**（必须重启，不然连不上）
3. 左侧活动栏点 **Claude Code 图标**（火花形状），右侧弹出聊天面板
4. 输入你的第一句话试试：`你好，帮我看看这个文件夹里有什么`

## 完成标志

✅ 聊天面板能正常回复你 = 全部搞定 🎉

## 常见问题

- **图标不显示？** 先打开一个文件（只开文件夹可能不显示）；还不行就重启 VS Code。
- **一直连不上/报错？** 九成是密钥没接对：回 cc-switch 确认选的是「Claude Code 终端版」并已"启动"，再重启 VS Code。
- **打开 VS Code 一片空白？** 确认第 1 步装的是 VS Code（不是别的编辑器）。
