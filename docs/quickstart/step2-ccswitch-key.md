# ② 装 cc-switch + 接密钥

cc-switch 是一个“切换开关”：Claude Code 用哪个模型供应商，由它控制。**本指南的 30 分钟上手路径需要装它完成首次配置。**

## 操作步骤

### 1. 让豆包帮你装 cc-switch

把下面这句话**原样复制**发给豆包：

::: tip 📋 发给豆包的话
帮我安装 cc-switch 最新版，在我的 D 盘，并在桌面上放快捷方式
:::

豆包会自动下载、安装、放好快捷方式。装完桌面会出现 cc-switch 图标。

> ⚠️ 如果豆包装失败了，让它"换一种方式再试一次"，或者找 IT 手动装。

### 2. 打开 cc-switch

双击桌面上的 cc-switch 图标，打开它的界面。

### 3. 接入你的密钥

**这一步很关键，必须在 cc-switch 里选「Claude Code 终端版」再接入密钥**——选错了，后面打开 Claude Code 会说连不上。

把 IT 发给你的 API Key 粘贴进去，保存。

::: danger 🔴 安全红线
- 密钥 = 账号密码。**别发群里、别截图外传、别发给同事帮你接**
- 豆包帮你操作可以（本地操作），但别把密钥发到任何群里
- 如果怀疑密钥泄露了，找 IT 重新生成一个
:::

## 完成标志

✅ cc-switch 打开后有你的密钥配置，能"启动/切换"

## 常见问题

- **cc-switch 列表是空的？** 需要先新建配置，把 API Key 和接口地址填进去——拿不准就问 IT，别自己乱填。
- **选成了"插件版"而不是"终端版"？** 删掉重来，这一步必须选 **Claude Code 终端版**。
