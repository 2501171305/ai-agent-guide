# ① 装豆包（AI 安装助手）

豆包是字节的免费 AI 软件。**它最大的用处：能听懂你的话，帮你安装其他软件。**

## 操作步骤

### 1. 下载安装豆包电脑版

1. 浏览器打开 <https://www.doubao.com>（或应用商店搜"豆包"）
2. 下载 **Windows 电脑版**，双击安装
3. 用手机号登录

> 💡 豆包免费，不需要密钥。

### 2. 让豆包认识你的电脑

打开豆包，第一次会提示**检测/扫描你的电脑**——同意它。它会扫描你的盘符，知道软件该装哪，后面帮你装软件才装得准。

::: tip 为什么要扫描？
豆包需要知道你电脑的情况（比如 D 盘在哪），才能按你的要求"装到 D 盘"。这是本地操作，豆包不会把你的文件传到网上。
:::

### 3. 验证装好了

能正常和豆包对话 = 成功。

## 完成标志

✅ 豆包能打开、能聊天、能扫描你的电脑

## 常见问题

- **扫不到 D 盘？** 确认电脑确实有 D 盘（打开"此电脑"看）。只有 C 盘也没关系，后面让豆包装软件时不说盘符就行。
- **不想让豆包扫描？** 不扫描也能用，但豆包帮你装软件时可能装错位置，建议还是扫一下。
