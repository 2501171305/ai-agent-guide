# 业务工作流

> 这一节是团队自己做的"活"，教你怎么用公司里的机器人（bot）完成日常业务。**不用装任何东西，在飞书 / 企业微信里发消息就行。**

---

## 一图看懂：哪个业务用哪个入口

| 业务 | 在哪用 | 怎么触发 |
|------|--------|---------|
| 生成工艺单 | 飞书群 | @ClaudeCode 发「生成工艺单 + 单号」 |
| 生成效果图 | 企业微信 | 发衣服底图 + 文字需求 |
| 添加定制器 | 飞书群 | @ClaudeCode 发京东链接 |
| 竞品分析 | 飞书群 | @ClaudeCode 发天猫/淘宝链接（暂未开放） |
| 快车推广计划 | 飞书群 | @ClaudeCode 发「创建快车计划」（暂未开放） |

> ⚠️ 简单记：**飞书 = 工艺单 / 定制器 / 竞品 / 快车；企业微信 = 效果图 + 数字人答疑。**

---

## 两个入口分别是什么

### 飞书里的 @ClaudeCode

飞书群里，`@ClaudeCode` 一下，再发你的需求，它就帮你干。这是主力入口。

### 企业微信里的数字人 / 效果图 Bot

企业微信群里，发消息给机器人。目前有两个用途：
- **数字人分身**：问工作相关的问题，它答
- **效果图**：发衣服照片 + 文字需求，它生成效果图

---

## 从哪个开始学

按使用频率，建议先会这三个：

1. [生成工艺单](/workflow/craftsheet) —— 最常用
2. [生成效果图](/workflow/effect-image) —— 服装业务高频
3. [添加定制器](/workflow/customizer) —— 上架定制商品
