# 生成效果图

## 这是干嘛的

效果图就是把 **LOGO / 文字印到衣服上**，让你提前看到成品长什么样，给客户确认用。

在企业微信群里发消息就能做，不用开任何软件。

---

## 三步流程

### 第 1 步：发衣服底图

在企业微信群里，发一张**衣服的照片**（底图）。机器人会回复「已收到底图」。

> 📸 【截图占位】企微群发衣服底图

### 第 2 步：发文字需求

底图确认后，发你的需求，格式是：

```
位置 + 文字 + 字体颜色
```

**例子**：

```
前胸文字：品牌名（黑体红色），后背文字：品牌名（黑体白色）
```

> 📸 【截图占位】发文字需求的格式

### 第 3 步：收到效果图

机器人会根据需求生成效果图发回群里。不满意可以继续微调（见下）。

---

## 可选位置

前胸 / 左前胸 / 右前胸 / 后背 / 左袖 / 右袖 / 领口 / 下摆

---

## 微调位置

生成的图位置不对，不用重做，直接发方向词微调：

- 「前胸往左」「后背往上」
- 「前胸30%,20%」（精确百分比坐标，第一个是左右，第二个是上下）

每次微调后都会重新生成一张。

> 📸 【截图占位】微调前后的效果图对比

---

## 加 LOGO 贴图

如果要把一个 **LOGO 图片**贴到衣服上：

1. 第一张图发**衣服底图**
2. 第二张图发 **LOGO 图**
3. 再发文字说明贴在哪（比如「贴左前胸」）

机器人会把两张图合成一张效果图。

---

## 常见问题

### 1. 效果图位置不对

用上面的方向词微调，别重新从头做。

### 2. 没收到「已收到底图」的回复

说明机器人没识别到底图，重新发一次，确保是清晰的服装照片。
