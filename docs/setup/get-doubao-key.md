# 申请豆包（火山方舟）API Key

> 💡 豆包的 Key 是给「看图」「生图」功能用的（效果图等）。大多数情况找 IT 领，这一页是**备用教程**——需要自己申请时照着做。

---

## 第 1 步：注册火山引擎账号

1. 打开浏览器，访问 <https://www.volcengine.com>
2. 用手机号注册并登录
3. **完成实名认证**（不实名没法用 API）

> 📸 【截图占位】火山引擎官网 + 实名认证入口

---

## 第 2 步：进入火山方舟（ARK）

1. 访问 <https://console.volcengine.com/ark>
2. 首次进入按提示**开通服务**

> 📸 【截图占位】火山方舟控制台

---

## 第 3 步：创建 API Key

1. 左侧菜单找「**API Key 管理**」
2. 点「**创建 API Key**」
3. 起个名字，创建
4. **立即复制保存**（Key 一般只完整显示一次）

> 📸 【截图占位】创建 API Key 页面

> 💡 豆包的 Key 格式可能是 `ark-` 开头，也可能是一串字母数字，**以平台实际显示为准**。

---

## 第 4 步：开通需要的模型

光有 Key 还不够，还得**开通对应模型**：

1. 左侧进「**模型广场**」或「**开通管理**」
2. 按需开通：
   - **豆包视觉模型**（看图用）
   - **豆包 Seedream**（生图用）

> 📸 【截图占位】模型广场开通模型

---

## 记下这个接口地址

```
https://ark.cn-beijing.volces.com/api/v3
```

---

## 安全提醒

和 DeepSeek 一样，豆包 Key 也是账号密码，**别外传**。更多见 [怎么避坑](/experience/how-to-avoid-pitfalls)。
