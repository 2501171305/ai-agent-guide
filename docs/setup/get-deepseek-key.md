# 申请 DeepSeek API Key

> 💡 大多数情况下，Key 由 IT 统一分发，你直接领就行。这一页是**备用教程**——当你需要自己注册一个 DeepSeek 账号、申请自己的 Key 时照着做。

---

## 第 1 步：打开 DeepSeek 开放平台

1. 打开浏览器，访问 <https://platform.deepseek.com/>
2. 登录后进入 API 控制台（注意：**不是**网页聊天，网页聊天不用 Key）

<!-- 截图待补：DeepSeek 官网，红框标出「API 开放平台」入口 -->

---

## 第 2 步：登录 / 注册

跳转到开放平台登录页后，选一种方式登录：

- **手机号登录**：输手机号 → 收短信验证码 → 登录（没注册过的号会自动注册）
- **微信扫码登录**：手机微信扫码

<!-- 截图待补：登录页面 -->

---

## 第 3 步：充值（余额不够才需要）

登录后进控制台，点左侧「**用量信息**」看余额：

- 余额够 → 跳过这步
- 余额为 0 或不足 → 点「**充值**」，选金额（¥10、¥20 都行），支付宝/微信付款

<!-- 截图待补：用量信息页面，红框标出充值按钮 -->

---

## 第 4 步：创建 API Key

1. 点左侧菜单「**API Keys**」
2. 点右上角「**创建 API key**」
3. 起个名字（比如 `我的工作用`），点创建
4. 页面会显示一串 **`sk-` 开头**的密钥

<!-- 截图待补：创建 API Key 的页面 -->

---

## 第 5 步：立即复制保存（关键！）

点「**复制**」把整串 Key 复制下来，存到安全的地方。

> ⚠️ **这串 Key 只完整显示一次**！关掉弹窗后就再也看不到完整的了，只能删掉重新创建。所以务必当场复制保存。

<!-- 截图待补：Key 创建成功、只显示一次的提示 -->

## 记下接口地址

DeepSeek 的 API 基础地址是：

```
https://api.deepseek.com
```

Claude Code 使用 DeepSeek 的 Anthropic 兼容接口，因此配置时填写：

```
https://api.deepseek.com/anthropic
```

如果 IT 提供了其他网关地址，以 IT 提供的为准。具体配置见 [给 Claude Code 接 DeepSeek](/setup/claude-code-deepseek)。

---

## 安全提醒

Key 就是你的账号密码，**别发群里、别截图、别贴文档**。更多安全红线见 [怎么避坑](/experience/how-to-avoid-pitfalls)。
