# 模型接入

装好工具只是第一步。要让工具真正"聪明"起来，还得给它接上**模型**——也就是告诉它"用哪个大脑"。

这一节讲清楚：公司用哪些模型、API Key 从哪拿、每个工具怎么接。

---

## 公司用哪些模型

| 模型 | 干什么用 | 用在哪个工具 |
|------|---------|-------------|
| **DeepSeek** | 文本对话、写东西、干活（主力） | Claude Code |
| **豆包（火山引擎 ARK）** | 看图、生成效果图 | Claude Code 的视觉/生图功能 |

> 简单记：**主力对话用 DeepSeek，要让它看图/生图时用豆包。**

---

## 什么是 API Key

**API Key 就是工具的"账号密码"**。

你去任何模型平台（DeepSeek、豆包）用它们的模型，都得先有个 Key，证明"我是谁、能用多少额度"。填进工具后，工具才能调用那个模型。

### Key 从哪拿

**找 IT 领取**，不要自己去注册充值。IT 会统一分发，并告诉你对应的接口地址（下面会用到）。

> ⚠️ **再次强调**：Key 就是密码，**不要发群里、不要截图、不要贴文档**。填的时候找 IT 一对一。
