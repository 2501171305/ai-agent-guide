# 怎么避坑

> 这些坑，都是团队里有人真踩过的。提前看一眼，能省掉很多返工。

---

## 新手最容易掉的 5 个坑

### 1. 把 Agent 当百度

以为它只能"搜答案"，于是用它查个东西就关掉。**这是最大的浪费**——它能干的是"帮你把活干完"，不只是"告诉你答案"。

> 别问"什么是周报"，直接说"帮我写本周周报"。

### 2. 第一次输出不满意就放弃

第一次给的东西不合心意，就直接关掉不用了。**错了，你该做的是告诉它哪里不对，让它改。**

它不会一次就完美，但你反馈一次，它就好一截。多用几次，你会摸到它的脾气。

### 3. 不知道可以换模型

一个模型不行，不代表工具不行。**可以换"大脑"**（见 [cc-switch](/tools/cc-switch)）。这个模型答得不好，换个模型试试。

### 4. 每次都从零开始描述

每次都要把背景、要求从头说一遍。**该把常用的存成模板**——第一次调顺之后，存下来，下次复制改字就行。

### 5. 一个窗口聊所有事

写周报、问技术、聊闲天全塞进一个对话里。这样它容易被之前的内容带偏。

**正确做法**：不同的事，开不同的对话。一个对话只干一件事。

---

## 安全红线：这几件事绝对不能做

这部分比上面所有坑都重要，**务必记住**：

### ❌ 绝对不要输入这些

- **客户真实信息**：姓名、电话、身份证号
- **财务原始数据**：报表原件、工资明细
- **未公开的商业计划**：还没上线的项目方案
- **API Key / 数据库密码**：任何密钥、密码

### 为什么

Agent 背后的服务会把你的输入发到云端处理。**你输入什么，就可能被记录、被用于训练**。敏感信息一旦进去，就收不回来了。

### 正确做法

- 用**脱敏数据**：客户张三 → 客户 A；真实电话 → 138xxxx
- 密钥、密码**一律不贴进对话**，用配置/环境变量的方式填（找 IT）
- 拿不准算不算敏感，**先问 IT**

> ⚠️ **尤其 API Key**：它就是你的账号密码。发到群里、贴到文档里、截图外传——任何一个动作都等于把账号密码交出去。任何人拿到你的 Key，就能用你的额度、甚至冒用你的身份。
