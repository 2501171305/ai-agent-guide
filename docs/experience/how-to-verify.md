# 怎么验证

> Agent 很能干，但**它会一本正经地犯错**。这一页教你怎么判断它给的答案靠不靠谱。

---

## 一句话原则

**判断标准不是"它说做好了"，而是"结果真的能用"。**

团队最早踩过的坑：Agent 回复"已生成"，大家都以为完事了，结果群里根本没收到东西。从那以后，我们定了条铁律——**验证标准是"结果能用"，不是"它说完成了"。**

---

## Agent 最容易在哪出错

### 1. 编造（也叫"幻觉"）

它会给出一个**听起来头头是道、其实是编的**答案。比如你问它一个数据，它可能编一个看起来合理的数字，而不是说"我不知道"。

**怎么防**：关键数字、日期、人名、客户信息，**一律自己核对一遍**，别直接抄它的。

### 2. 会错意

你问的是 A，它理解成 B，然后对着 B 干得很起劲。

**怎么防**：拿到结果先看一眼，是不是你要的那件事。不是就立刻纠正。

### 3. 半途而废

它说"做完了"，其实只做了一半，或者漏了某个文件。

**怎么防**：重要的活，**打开结果确认一下**，别只看它那句"已完成"。

---

## 三类事，验证方式不一样

| 类型 | 怎么验证 |
|------|---------|
| 写文档 / 周报 | 通读一遍，看有没有胡编的数字、错的事实 |
| 整理数据 / 表格 | 抽查几个数，和原始数据对一下 |
| 写代码 / 自动化 | 实际跑一遍，看能不能跑通、结果对不对 |

---

## 一个简单有效的习惯

**拿到结果，先问自己一句：这个我能直接拿去用吗？**

- 能 → 收工
- 不能 → 告诉它哪里不对，让它改，再验一次

不要因为它"看起来挺专业"就跳过这一步。**它专业的外表，恰恰是你最该留个心眼的地方。**
